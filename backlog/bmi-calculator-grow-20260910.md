
# 判定区分の帯と現在地マーカーで、BMI が区分のどのあたりにあるかを一目で示す

いまの画面は BMI 値と「普通体重」「肥満（1度）」という判定ラベルだけを出すので、同じ「普通体重」でも下限の 18.5 に近いのか上限の 25 に迫っているのかは、利用者が FAQ の境界値を思い出して自分で位置づけるしかない。BMI 24.6 は「普通体重」と表示されるが、あと少しで区分が変わることは数字と文字からは読み取れない。判定の下に、低体重から肥満（4度）までの 6 区分を左から順に並べた帯を置き、境界値 18.5・25・30・35・40 の目盛りを打ち、現在の BMI の位置にマーカーを立てる。現在の区分だけを強調すれば、ラベルの根拠と、隣の区分までの余裕が、数字を読まずに視覚で伝わる。

## 意図

体重計に乗った直後に BMI を確かめる人が、判定ラベルの「余裕」を知るために使う。
「普通体重」でも上限ぎりぎりなら気をつけ、真ん中なら安心できる。その差は数字よりも帯上の位置のほうが速く伝わるため。

## 受け入れ条件の種

- 身長170・体重60 を入力すると `#result` 内に `#bmi-scale` が表示され、低体重・普通体重・肥満（1度）〜（4度）の 6 区分が左からこの順で並び、境界値 18.5・25・30・35・40 の目盛りラベルが読める。現在の区分（普通体重）だけに強調用クラスが付き、そのテキストは `#bmi-label` と一致する
- `#bmi-marker` は BMI を 15〜45 の線形スケールに置き、`style.left` を `(BMI−15)÷30×100` % とし、範囲外は 0% と 100% に丸める。身長100・体重24（BMI 24.0）では 30%、身長100・体重30（BMI 30.0）では 50%、身長100・体重60（BMI 60.0）では 100% で帯の右端にとどまる。`aria-valuenow` に `#bmi-value` と同じ小数第1位の BMI 値を持つ
- `#bmi-value` と `#bmi-label` のテキストは現在と変わらない。片方が未入力または 0 以下のときは `#bmi-scale` と `#bmi-marker` を描画せず、`#result` はプレースホルダ文言だけになる。既存の `tests/app.spec.ts` がすべて通る
